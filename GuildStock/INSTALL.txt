GuildStock 0.3.4 - automatic synchronization testing build
WoW Forever beta 1.60.1, build 70205, interface 16001

Install the same version on every participating client.
Extract this ZIP inside World of Warcraft/_classic_beta_/Interface/AddOns/.
The resulting path must be Interface/AddOns/GuildStock/GuildStock.toc.
Restart the game after installing this version, then enable GuildStock and log in.
No commands, profession scans or remote access to another PC are needed.

The base catalog includes 589 materials and 1083 associations across 12 professions.
Names and icons use each client's game data. The catalog is not exhaustive.

Guild inventory discovery starts automatically after guild and inventory are ready.
Open GuildStock to see received Characters and material-owner rows.
Discovery replies wait for the offer cooldown instead of being discarded.
Later changes are grouped for five minutes from the first pending change.
No periodic network heartbeat is sent while inventories remain unchanged.
Uncheck Share to exclude an item from the next complete replacement.
Observed material IDs are remembered per character, including across reloads.
Visit the character bank once to discover materials already stored only there.
Known material counts combine bags and the character bank in one total.
Only known IDs are counted at login; changes refresh affected materials.
The addon does not query every material in the catalog.
Counts include owned bound items; they are not guarantees of tradeability.

All addon traffic uses GUILD. Settings reports messaging restrictions or waiting.
If the beta blocks addon messages, local inventory remains available and the
addon does not bypass that restriction. Local peer reception has been observed;
remote display and cross-shard delivery still need independent verification.
Complete peer inventories are saved per character and restored after guild membership
can be verified. New synchronization refreshes the dated history in the background.
Hover a player name for the age of its last complete update above the cursor.
Quantity columns now read Units. Login timing and five-minute change batches are unchanged.

Includes the dark interface and animated profession-section dividers.
